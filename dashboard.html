Each PIR is an independent finite-state machine. The latest Firebase PIR value is sampled every 1.5 seconds. Three consecutive true samples trigger its relay pair for 30 seconds. PIR 1 controls relays 1–2 and PIR 2 controls relays 3–4. Both state machines run independently, so their 30-second timers can overlap. Temperature never turns appliances on or off, and manual switches remain available even when sensors are offline.
